# Новости и цены: разведочный анализ

Материалы по теме «Двигают ли новости цены акций?» — корпус новостей и
раскрытий против дневных и минутных котировок MOEX и рынка США.

## Что здесь лежит

| файл | что это |
|---|---|
| `Новости_и_цены_EDA.pdf` | доклад с результатами |
| `EDA_report_executed.ipynb` | отчёт с посчитанными числами и рисунками |
| `EDA_report.ipynb` | тот же отчёт без выполнения, для чтения кода |
| `EDA_report.html` | он же одним файлом для браузера |
| `ход_работы.md` | как собирались данные и что на каждом шаге пошло не так |
| `результаты.md` | методики, формулы и итоговые числа по главам |
| `CONTRACT.md` | договор между расчётами и витриной: какие таблицы и с какими колонками |
| `artifacts/` | снимок замеров, из которого собран отчёт |

## Как читать

Отчёт ничего не считает сам: он читает готовый снимок из `artifacts/` и
рисует. Поэтому числа в нём воспроизводятся без доступа к озеру данных —
достаточно открыть `EDA_report_executed.ipynb` или `EDA_report.html`.

У каждого рисунка снизу подписан источник: имя файла в `artifacts/`,
число строк, время замера и отпечаток сборки. Если число в тексте
расходится с рисунком — верен рисунок.

## Чего здесь нет

Самих данных: корпус документов и котировки живут отдельно и в репозиторий
не кладутся. Здесь только агрегаты, из которых получен отчёт.
