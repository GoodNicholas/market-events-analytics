Отчёт о методах и результатах на 09.11.2026. Всё — по периоду разработки
(dev) до **30.06.2025** включительно; холдаут за этой границей не
открывался ни разу (`mea.eda.split.assert_dev_only` стоит в загрузчиках).

Каждое число приводится с 95 % интервалом. Правила интервалов едины для
всего проекта:

* **доли** — интервал Уилсона (не нормальное приближение: при доле у края
  оно выходит за [0, 1]);
* **ряды** — блочный бутстрап, длина блока `n^(1/3)` (правило
  Политиса–Уайта в простейшем виде). Обычный бутстрап переставляет
  наблюдения независимо и убивает автокорреляцию, а у нас её полно:
  волатильность кластеризуется;
* **величины, усреднённые по бумагам** — бутстрап по бумагам, не по точкам
  ряда;
* **событийные величины** — бутстрап по **датам**: в один день
  отчитываются десятки компаний, и их доходности зависимы. Семь миллионов
  пар «бумага-день» у США — это примерно 2 625 независимых дней, а не семь
  миллионов наблюдений.

**Ограничение, действующее на всю работу.** На минутных данных миллионы
баров, и тест значимости отвергает почти любую нулевую гипотезу: при
n = 60 000 Льюнг–Бокс отвергает отсутствие автокорреляции уже при её
величине **0,01** (проверено на модели, где автокорреляции нет по
построению). Поэтому выводы ведутся по **размеру эффекта** с интервалом, а
p-значения идут справкой.

## 1. Что построено: слои данных и как они собраны

### 1.1 Конвейер

```
docs (сырые документы)
  → clusters      дедупликация: точное совпадение + MinHash/LSH
  → doc_flags     бойлерплейт, язык, подозрительная дата, price-recap
  → mentions      привязка документа к эмитенту (алиасы + роли + ярус)
  → events        событие = (документ × бумага) с ярусом ≥ порога
  → features      признаки по (бумага, день)
quotes (бары)
  → adj_prices    цена, скорректированная на корпоративные действия
  → targets       цели: аномальная доходность, объём, окна
```

| слой | строк | период |
|---|---|---|
| `docs` | 59 360 993 | 1999…2026 (основной объём с 2012) |
| `clusters` | 9 840 199 | дедуп |
| `doc_extra` | 41 318 467 | бойлерплейт + словарная тональность |
| `mentions` | 14 209 812 | 1999…2026 |
| `events` | 3 906 051 | 2004…2026 |
| `features` | 1 570 295 | 2015…2026 |
| `edgar_filings` | 2 266 706 | ключ `(adsh, cik)` уникален |
| `quotes` | 46 492 124 | 1962…2026 |
| `adj_prices` | 30 981 355 баров | слой анализа |

### 1.2 Дедупликация

Точное совпадение по хэшу текста, затем near-duplicate: **MinHash, 128
перестановок, шинглы по 5 слов, порог Жаккара 0,9**, скользящее окно ±3 дня,
склейка компонент связности (union-find).

Поймано на этом этапе: **мега-кластер из 10 318 088 документов** — все они
имели SHA-1 **пустой строки**, потому что текста у них нет (у FNSPID текста
нет у 81 % документов). Ключ дедупа после этого многоуровневый: текст →
заголовок → `doc_id`.

### 1.3 Привязка документа к эмитенту

Словарь алиасов (названия, формы, тикеры) + поиск **Ахо-Корасика** с
проверкой границ слова **с двух сторон** и регистронезависимостью, плюс
закрытый список **21 русского падежного окончания**; стем = алиас минус
конечная гласная или мягкий знак.

Каждому упоминанию присваивается **роль** (`subject`, `context`, `source`,
`analyst`, `reference`) и **ярус релевантности** `relevance_v2` 10…100.
Ярус — единственные ворота событий; основной анализ идёт по `score = 100`.

Качество привязки измерено на размеченных холдаутах по 400 документов на
язык, эталон — согласие двух независимых прогонов плюс арбитраж:

| | ошибка топ-яруса ≥ 90 | при `score = 100` | строгая точность | потеря истинных |
|---|---|---|---|---|
| **RU** | 4,0 % [2,0; 8,0], n=175 | **3,6 %** | 90,3 % | 35,4 % |
| **EN** | 15,6 % [11,1; 21,5], n=186 | **12,0 %** | 76,3 % | 42,7 % |

Воронка по этапам (доля документов): RU 30,0 → 23,9 → 4,7 → **3,6 %**;
EN 17,0 → 6,6 → 5,4 → **4,2 %**.

Причина провала английского названа и однопричинна: 18 из 29 ошибок
топ-яруса — агрегаторные жанры (сводки сектора, опционная активность,
притоки в ETF, маркетинговые отчёты с перечнем вендоров). Счётчик субъектов
в заголовке считает сущности, а в таких заголовках стоят **тикеры**,
которых словарь не ищет. В русском этого жанра нет.

### 1.4 Правило дня события (safe bar)

Публикация отображается на торговый день так: **любой момент внутри
календарного дня D относится к открытию СЛЕДУЮЩЕЙ сессии**, если время
внутри дня неизвестно. Если время известно, подача до 16:00 по бирже —
тот же торговый день, позже — следующий.

Это правило определяет всё остальное, потому что **у 97 % событий США и
84 % России в отметке публикации стоит ровно полночь**: известна только дата.

### 1.5 Ценовой слой

`adj_prices` строится из `quotes` умножением на накопленный множитель
корпоративных действий (`cum_factor`), и три решения тут принципиальны.

**Коэффициенты сплитов не выводятся из отношения цен.** Проверка: MOEX:TRNFP
давал «1:104» вместо настоящего 1:100, US:EXE — «123:1» вместо 1:200.
Применяются только подтверждённые документом коэффициенты; правило в коде:
ручное действие применяется, если
`|заявленный коэффициент / фактический шаг − 1| ≤ 10 %`, иначе сборка
останавливается с перечнем. Действие с документом (`doc_url`) применяется
всегда, остаток шага уходит в лог как рыночное движение.

**Доходность через стык двух лент не существует.** У США `fnspid` до
2023-12-28 и `alpaca_sip` с 2024-01-02 имеют разные базы корректировок.
Замер на 13 134 переходах по 7 743 бумагам:

| основа | медиана \|r\| | 99-й процентиль | доля движений > 25 % |
|---|---|---|---|
| `close`, внутри источника | 0,0097 | 0,131 | 0,27 % |
| `close`, шов | 0,0088 | 5,32 | 7,39 % |
| `adj_close`, внутри источника | 0,0098 | 0,140 | 0,35 % |
| **`adj_close`, шов** | **0,1091** | 6,27 | **36,46 %** |

Поэтому цепочка доходностей рвётся на смене источника **по построению**, а
окна анализа лежат целиком внутри одной ленты.

**Оборот считается по сырой цене на объём, а не по `adj_close`.** Отношение
`adj_close` к `close` доходит до **900 000** (US:CNSP), и топ-50 по обороту,
посчитанный через скорректированную цену, определялся артефактом — в него
попадали пенни-стоки с обратными сплитами (WHLR, ADTX, SXTC, JAGX) вместо
ликвидного ядра.

**Единая точка чтения.** `prices_select` — единственное место, где
применяются отсев лент по качеству (`price_quality`) и обрезки
(`tape_cuts`). Слой держит все ленты; фильтрация происходит при чтении.
Это нужно потому, что качество считается ИЗ слоя, и фильтровать слой по
нему — круговая зависимость (при её разрыве **197 лент**, помеченных
плохими, оказались здоровыми).

Цена дисциплины, измеренная: исключено 118 плохих лент США (116 бумаг),
обрезано 123 ленты, отброшено **102 708 дней**; из 95 904 событийных дней
США **5 429 (5,7 %)** остались без полного окна оценки.

Приёмка слоя: детектор `|log r| > 2` по всей ленте. Всего необъяснённых
**15 212 = 0,049 %** баров (из них 12 234 — `fnspid` до 2016);
**в окне анализа после приёмки — 0**.

### 1.6 Цели и аномальная доходность

| величина | определение |
|---|---|
| доходность | `r_t = ln(P_t / P_{t−1})`, логарифмическая — чтобы складываться по периодам |
| окно оценки беты | **[−250, −30]** торговых дней, минимум **60** наблюдений |
| бета | `β = cov(r_i, r_m) / var(r_m)` по совпадающим дням окна оценки |
| аномальная доходность | `AR_t = r_t − β · r_{m,t}` (рыночная модель) |
| накопленная | `CAR[a,b] = Σ_{k=a..b} AR_{t+k}` |
| горизонты | 1, 2, 5, 10, 20 дней |

Целей построено: RU **247 634**, US **11 365 953**.

Конвенция индексов, из-за которой был пойман дефект: `prices_select` отдаёт
цены длиной N и доходности длиной N−1, элемент k — доходность дня `d[k+1]`.
Индексировать доходности датным индексом нельзя.

### 2.2 Глава 05, пункт 1: хвосты распределений

**Что меряли и как.** Избыточный эксцесс (у нормального распределения 0);
оценка **Хилла** индекса хвоста отдельно для левого и правого хвоста;
проверка нормальности; агрегационная гауссовость (минута → 5 минут → 30
минут → день → неделя).

**Вселенная:** 50 бумаг с наибольшим оборотом среди членов индекса рынка
(IMOEX / SPX), торговавшихся не менее 95 % дней окна. Членство в индексе
задаёт сопоставимое по смыслу ликвидное ядро и убирает из вселенной США
биржевые фонды (по обороту SPY и QQQ обгоняют любую акцию).

агрегацией» на нём неверно.

### 2.3 Глава 05, пункт 2: автокорреляция, кластеризация, долгая память, рычаг

**Что меряли.** ACF доходностей и их модулей на лагах 1…40 рядом с полосой
`1,96/√n` (без полосы максимум нечитаем: у белого шума на тысяче точек он
сам по себе около 0,075). Долгая память — показатель **Хёрста методом DFA**
(независимый шум 0,5; случайное блуждание 1,5) и оценка **GPH** параметра
дробного интегрирования `d`. Эффект рычага — корреляция `r_t` с `|r|_{t+k}`.

**Контроль, без которого вся долгая память была бы артефактом:** тот же
показатель Хёрста считается на самих доходностях, и он обязан остаться около
0,5. Он не ушёл: **0,43–0,52 по всем строкам**.

| ряд | окно | ACF(r,1) | ACF(\|r\|,1) | Хёрст \|r\| | контроль на r | GPH d (\|r\|) | рычаг k=1 |
|---|---|---|---|---|---|---|---|

есть падение предсказывает рост волатильности.

не из-за размера выборки. На минутных данных автокорреляция первого порядка
велика по размеру эффекта, и знак у неё разный:

|---|---|---|---|
| RU, 8 акций MOEX | 18,2 % | **−0,3015** | 0,0016 |
| US-бумаги на СПБ | 14,6 % | −0,1322 | 0,0019 |
| US, Alpaca SIP | 4,6 % | −0,0733 | 0,0036 |
| RU, индекс IMOEX | 0,9 % | **+0,1298** | 0,0023 |

Знак выстраивается **по ликвидности, а не по стране**: чем больше минут
проходит без сделки, тем сильнее отрицательная автокорреляция (18,2 % нулей
→ −0,302; 4,6 % → −0,073). Это отскок между спросом и предложением
(bid-ask bounce). У индекса знак обратный, потому что он считается по
бумагам, торгующимся не одновременно, и часть составляющих входит вчерашней
ценой. Обе величины — свойства измерения, а не предсказуемости.

### 2.4 Глава 05, пункт 3: объём против волатильности, асимметрия

**Нормировка объёма** обязательна: логарифм отношения к медиане
предыдущих 60 торговых дней. У сырого объёма есть и тренд (за десять лет
оборот меняется на порядки), и свой уровень у каждой бумаги — корреляция
сырого объёма с волатильностью измерила бы совпадение трендов.

**Грейнджер отчитывается ДОЛЕЙ бумаг**, у которых направление отвергается
при уровне 1 %, с интервалом Уилсона — а не одним p-значением. На двух
тысячах наблюдений p почти всегда мало и говорит о размере выборки; у доли
есть содержательный масштаб (5 % — уровень ложных срабатываний, 90 % —
свойство рынка).

| ряд | corr(\|r\|, объём) | объём → волатильность | волатильность → объём |
|---|---|---|---|
| RU, 50 бумаг | 0,395 [0,367; 0,411] | 8 % [3; 19] | **92 % [81; 97]** |
| US, 50 бумаг | 0,464 [0,451; 0,488] | **60 % [46; 72]** | 20 % [11; 33] |

**Направление связи противоположно на двух рынках**, и это проверено на
устойчивость: перебраны окно нормировки (20 и 60 дней), мера волатильности
(модуль и квадрат) и число лагов (3, 5, 10) — двенадцать спецификаций на
рынок. Направление сохраняется **12 из 12** на обоих рынках; величина доли
— нет (мера волатильности меняет её вдвое). Поэтому в выводе стоит
направление, а не число.

**Асимметрия прибыль/убыток по определению Cont (2001)**: сколько торговых
дней нужно, чтобы впервые набрать заданную прибыль, и сколько — такой же по
величине убыток. Выборочная асимметрия распределения это не заменяет: она
может быть около нуля при сильной асимметрии времён.

| ряд | асимметрия | ±5 % | ±10 % | ±20 % |
|---|---|---|---|---|
| RU, портфель | −7,44 [−10,14; −0,70] | 40/42 = 0,95 | 89/87 = 1,02 | 169/97 = **1,74** |
| RU, IMOEX | −7,52 [−10,22; −0,11] | 35/36 = 0,97 | 85/58 = 1,47 | 165/98 = 1,68 |

Асимметрия появляется только на крупных уровнях: на ±5 % отношение около

быстрее прибыли» — утверждение про обвалы, а не про обычные колебания.

### 2.5 Глава 05, пункт 4: внутридневная сезонность

**Формула профиля.** Для каждой пары (бумага, день) значение минуты делится
на среднее по минутам **того же дня у той же бумаги**. Множитель 1 читается
как «как в среднюю минуту этого дня». Сравнивать уровни |r| между бумагами
нельзя: волатильность различается на порядок, и средний профиль определялся
бы самой бурной бумагой. Деление внутри дня заодно убирает тренд уровня
волатильности по годам.

### 2.6 Глава 05, пункт 7: календарные эффекты

**Формула.** Эффект — безразмерный множитель **внутри своей недели** (для
дня недели) или **внутри своего месяца** (для конца месяца): значение дня,
делённое на среднее по периоду у той же бумаги. Иначе «вторник выше
пятницы» померило бы состав выборки по годам. Интервал — бутстрапом по
**неделям** и **месяцам**, а не по дням.

Номер дня с конца месяца считается **по панели**, а не по календарю:
последний календарный день месяца часто нерабочий. Экспирация — третий
четверг; если он не торговый, берётся предыдущий торговый день, как это
делает биржа.

**День недели.** У России отчётливый убывающий профиль, у США плоский:

**ex-date: падает ли цена на дивиденд.** Меряется остаток

грошовой цены дивидендная доходность улетает, и среднее дало +33,7 п.п. при

## 3. Новости и рынок вместе (глава 06): описание без гипотез

### 3.1 Устройство измерения

**Величины** нормированы, иначе бумага за 1 рубль и бумага за 100 000
складываются в одно среднее:

* **размах** — `|r|`, делённое на стандартное отклонение той же бумаги за
  20 предшествующих торговых дней (`absr_n`);
* **оборот** — делённый на свою медиану за те же 20 дней (`turn_r`).

**Каждая разница считается четырьмя способами одной машинкой**, и это
главное методическое решение главы:

| вариант | что сравнивается |
|---|---|
| **C0** | день с событием против среднего по всем безновостным дням подпериода — сырая разница |
| **C1** | дни **одной бумаги внутри одного месяца** |
| **C2** | то же плюс день недели |
| **плацебо** | C1 на панели, где метка «день с событиями» переставлена **внутри каждой бумаги**: число новостных дней у бумаги сохранено, привязка ко дням разрушена |

Единица ресемплинга — **дата**, не пара.

### 3.2 Результат: контроль меняет даже знак

| величина | рынок | пар C1 | дат | C0 без контроля | C1 бумага × месяц | C2 + день недели | плацебо |
|---|---|---|---|---|---|---|---|
| размах | RU | 42 093 | 2 615 | 0,053 [0,029; 0,078] | **0,077 [0,052; 0,100]** | 0,076 [0,047; 0,101] | 0,008 [−0,009; 0,027] |
| размах | US | 1 613 179 | 2 625 | 0,133 [0,112; 0,154] | **0,173 [0,155; 0,192]** | 0,187 [0,166; 0,207] | 0,001 [−0,011; 0,013] |
| оборот | RU | 42 154 | 2 617 | **−0,615 [−0,740; −0,487]** | **+0,410 [0,307; 0,516]** | 0,527 [0,389; 0,677] | 0,052 [−0,012; 0,112] |
| оборот | US | — | — | — | **0,343 [0,322; 0,363]** | — | — |

**Сырое сравнение бессмысленно, и это измерено:** по обороту России оно даёт
**−0,615**, а сопоставленное — **+0,410**. Знак противоположный. Причина
измерена: новостные дни приходятся на крупные бумаги, безновостные — на
малые.

Сопоставленная разница: **+0,077** у RU и **+0,173** у US в единицах
собственного sd бумаги, то есть примерно **+10 %** и **+23 %** к уровню
контрольного дня. Плацебо накрывает нуль во всех четырёх случаях — машинка
сама по себе разницы не создаёт.

**Доза.** Разница растёт с числом событий в дне: у США от **0,092
[0,078; 0,106]** при одном событии до **1,383 [1,254; 1,518]** при десяти и
более. Но число событий наполовину измеряет внимание прессы, поэтому это
описание дозы, а не отклик на дозу.

**Дни крупного движения** (|r| выше 95-го процентиля той же бумаги в том же
подпериоде — один порог на всю панель сравнивал бы волатильные бумаги с
тихими): новостных среди них **20,1 [19,5; 20,7] %** у RU и **39,1
[38,9; 39,2] %** у US против базовых 16,2 % и 29,4 %.

**Ступень 2020 года.** Доля новостных дней у США делает скачок с 13 % в
2019 до 39 % в 2020. Так рынок не меняется — так меняется **состав
корпуса**. Поэтому подпериоды между собой в главе не сравниваются, а
сопоставление всегда идёт внутри месяца.

### 3.3 Реакция или только совпадение — главная оговорка работы

У **97 % событий США и 84 % России** известна только дата. Для таких
событий порядок «сначала новость, потом движение» внутри суток ничем не
подтверждён. Поэтому разница считается дважды:

| рынок | подвыборка | новостных дней | бумаг | размах: превышение | оборот: превышение |
|---|---|---|---|---|---|
| RU | настоящее время | 14 553 | 167 | 0,079 [0,040; 0,120] | 0,309 [0,162; 0,469] |
| RU | полночь | 44 871 | 224 | 0,089 [0,062; 0,113] | 0,516 [0,382; 0,659] |
| US | настоящее время | 154 813 | 3 125 | **0,187 [0,154; 0,219]** | 0,462 [0,352; 0,573] |
| US | полночь | 1 911 447 | 3 367 | 0,186 [0,167; 0,205] | 0,363 [0,342; 0,384] |

Превышение там, где время известно, — это движение **после** публикации,
его можно читать как реакцию. Превышение у полуночных означает только, что
новость и движение попали в одни сутки: это **ассоциация**.

**Чего этот разрез не делает.** Подвыборка с настоящим временем смещена по
источникам (минутные отметки есть не у всех лент и не во все годы), поэтому
сравнение двух столбцов — это сравнение разных наборов новостей, а не одного
набора с разной точностью времени. Сказать «во сколько раз реакция сильнее
ассоциации» нельзя.

## 4. Гипотезы: метод и результат по каждой

### 4.1 Общий аппарат событийного анализа

**Стандартизация накопленной доходности (BMP).** Для окна длиной T:

```
SCAR_i = CAR_i / (s_i · √T · fe_i)
```

где `s_i` — остаточное СКО окна оценки (ddof = 2: оценены альфа и бета),
`√T` — потому что дисперсия суммы T независимых остатков растёт как T
(без корня тест на окне [2, 60] завышает статистику в **√59 = 7,68 раза**),
`fe_i` — поправка Пателла на ошибку предсказания беты:

```
fe = √(1 + 1/M + (R_m0 − R̄_m)² / Σ(R_m,est − R̄_m)²)
```

Пол остаточного СКО **1e-6**: ниже это не СКО, а числовая случайность окна
(при 60 наблюдениях остатки иногда схлопываются до 1e-17, и такое событие
единолично решает t всей группы).

**Тест BMP:** `t = √N · mean(SCAR) / sd(SCAR)`.

**Поправка Kolari–Pynnönen** на кросс-секционную корреляцию:

```
t_KP = t_BMP · √((1 − r̄) / (1 + (N − 1)·r̄))
```

где `r̄` — средняя попарная корреляция остатков окна оценки, и в среднее
идут **только пары, чьи окна оценки могли пересечься календарно** (у
событий, разнесённых на годы, корреляция мерила бы совпадение позиции в
массиве, а не общий рыночный шок). Отрицательное `r̄` флоорится до нуля
перед подстановкой: отрицательная выборочная оценка при истинном `r̄ ≈ 0` —
обычный шум, и использование её как есть **усиливает** статистику, то есть
противоположно консервативной цели поправки.

**Плацебо** — обязательная часть каждой гипотезы: даты событий
переставляются **внутри бумаги**, то есть распределение событий у бумаги
сохраняется, а привязка ко дням разрушается. Эффект обязан исчезнуть.

### 4.2 H1 и H1b — новости в прогнозе волатильности

**Модель.** HAR (Corsi 2009): регрессоры — средние реализованной
волатильности за **1, 5 и 22** дня, окно включает текущий день и не
заглядывает вперёд. Новостная модель добавляет z-оценку внимания:

```
attention_z(t) = (n(t) − μ_{60}) / σ_{60}
```

где окно 60 торговых дней кончается на **t−1** (иначе сегодняшний всплеск
входит в собственную норму и z занижается), дни без новостей — нули, а не
пропуски, зажим ±50. Внимание мерится числом **уникальных сюжетов**
(`cluster_id`) яруса ≥ 30.

**Оценивание:** прогноз вперёд по расширяющемуся окну, переоценка раз в 22
торговых дня, **эмбарго длиной горизонта**: обучающая строка допускается
только если её прогнозное окно закончилось не позже чем за `h` дней до
начала проверочного блока. Коррекция Дуана на переход из логарифмов.

**Потеря QLIKE:** `a/f − ln(a/f) − 1`. Ноль при точном прогнозе, строго
положительна иначе, асимметрична — недопрогноз волатильности наказывается
сильнее перепрогноза.

### 5.2 C2 — вклад новостей сверх цен

**Постановка.** Две модели LightGBM на одних и тех же событиях:

* **P** — только цены: 8 признаков (прошлые доходности, волатильность,
  объём; окно кончается на баре **перед** движением, то есть утечки нет по
  построению);
* **P+N** — те же 8 плюс **эмбеддинг 1024** и тональность (1 025 новостных
  признаков).

**Два горизонта**, и это разделение принципиально:

* **nowcast** — цель включает день события ([i−1, i+1]). Слово
  «предсказывает» здесь не употребляется вовсе: документ приходит внутри
  окна цели, и при дате без времени может оказаться **после** движения;
* **forecast** — цель на день i+1, новостные признаки только из событий,
  известных к открытию i+1.

**Два задания:** AUC на бинарной цели «верхняя четверть |r|» и R² на
`log|r|`.

**Разбиение по времени**, доля теста 30 %, гиперпараметры фиксированы и не
подбирались. Прирост `P+N − P` с бутстрап-интервалом.

**Плацебо** перемешивает новостные признаки **внутри бумаги**: отпечаток
бумаги в них сохраняется, связь с конкретным днём разрывается.
Перемешивание по всей выборке завысило бы плацебо-прирост и тем самым
облегчило вывод.

**Важности** даются двумя способами и **по группам** (цены против новостей),
а не по признакам: gain из бустера и перестановочная.

**Правило формулировки задано до прогона:** «текст предсказывает» допустимо
только если прирост больше нуля, его интервал не накрывает ноль **и**
плацебо-прирост около нуля (меньше половины настоящего). Иначе — «модель
предсказывает, вклад новостей не выделен».

## 6. Контроль против самообмана

Это отдельный слой работы, и он объясняет, почему числам можно верить.

| контроль | как устроен | где применён |
|---|---|---|
| **Плацебо** | даты событий переставлены **внутри бумаги**: распределение событий у бумаги сохранено, привязка ко дням разрушена | H1, H2, H3, H4, H13, H14, H19, C2, глава 06 |
| **Сдвиг сигнала** | внимание дня t берётся от событий t−2 | H1, диагностики H1b |
| **Подпериоды** | P1 ≤ 2019, P2 2020–2021, P3 2022, P4 ≥ 2023 | главы 05, 06, диагностики H1b |
| **Ярусы как контроль** | эффект обязан расти с ярусом; если нет — привязка или гипотеза | H13 |
| **Разрез по известности времени** | реакция против ассоциации | глава 06.7 |
| **Разрез по классу источника** | пресса против раскрытий EDGAR | диагностики H1b |
| **Порог t ≥ 3** | Харви–Лю–Чжу вместо 1,96 | все гипотезы |
| **Поправка Холма** | внутри семейства гипотезы | реестр |
| **Реестр проверок** | 2 930 строк: хеш кода, время, хост, вид строки; аннулировано 1 326 со ссылкой на `id` | весь проект |
| **Сдутый Шарп** | `deflated_sharpe` с поправкой на число испытаний, асимметрию и хвосты | `controls.py`, H9 |
| **Холдаут** | не открывался ни разу; в целях виден только как счётчик пропусков (159 RU, 4 014 US) | — |

**Что дало это само по себе.** Плацебо накрывает нуль во всех четырёх
случаях главы 06 и в диагностиках H1b (t = 0,65) — то есть машинка сама
разницы не создаёт. А вот где контроль сработал как отсев: сырое сравнение
по обороту России дало **−0,615** против сопоставленного **+0,410**, то
есть без контроля знак был бы противоположным.

## 8. Что получилось: семь утверждений

1. **Дни с новостями отличаются от дней без — но только при правильном
   сопоставлении.** Размах движения выше на **+10 %** (RU) и **+23 %** (US)
   к уровню контрольного дня; по обороту +0,41 и +0,34 медианы. Сырое
   сравнение даёт противоположный знак.

2. **Это совпадение, а не доказанная реакция.** У 97 % событий США и 84 %
   России известна только дата. Там, где время известно, превышение
   сохраняется (US размах 0,187 [0,154; 0,219]), но подвыборка смещена по
   источникам, и во сколько раз реакция сильнее ассоциации — сказать нельзя.

3. **Новости улучшают прогноз волатильности — на 0,4 % потери HAR.**
   Единственный результат, прошедший все три диагностики: плацебо исчезло
   (t = 0,65), «несвежие» новости дают в 18 раз меньше, а раскрытия EDGAR с
   точным временем дают больше прессы (0,670 % против 0,400 %).

4. **Текст связан с величиной движения в день события, но не предсказывает
   его на следующий день.** Прирост R² +0,0160 [+0,0031; +0,0277] при
   плацебо 0,0000 на nowcast; на forecast интервал накрывает ноль. По
   России — нигде.

5. **Знаковой реакции на тональность не найдено.** H2: асимметрия
   негатив-позитив +3,87 п.п. [−11,78; 21,59] у RU и +0,34 [−1,29; 1,02] у
   US. Единственное исключение — неликвидная терция России: −0,541 п.п.
   [−1,15; −0,073].

6. **Среди раскрытий сильнее всех результаты за период.** 8-K item 2.02
   даёт 4,801 п.п. |AR[0,1]| против 1,78–2,45 у остальных классов; все
   разности с интервалами далеко от нуля на 519 204 наблюдениях.

7. **Реакция быстрая, но до открытия, а не в первый час торгов.** За час
   проходит 26,4 % хода и 14,1 % объёма, за два — 49,3 % хода; у
   внесессионных подач ночной разрыв объясняет **83,4 %** движения.

**И одно утверждение о самих данных, которое стоит рядом с остальными:**
рынок устроен так, как описывает классика (тяжёлые хвосты с индексом Хилла
2,0–3,3, отсутствие линейной автокорреляции, кластеризация волатильности,
долгая память с Хёрстом 0,81–0,95, отрицательный рычаг, асимметрия на
крупных уровнях) — **кроме минутных данных, где автокорреляция велика и её
знак определяется ликвидностью**, то есть является свойством измерения, а не
рынка.
