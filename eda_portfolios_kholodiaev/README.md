### Описание структуры датасета синтетических портфелей

Каждая строка датасета представляет отдельную позицию (акцию) в составе сгенерированного инвестиционного портфеля.

| Колонка | Описание |
|---|---|
| `portfolio_id` | Уникальный идентификатор портфеля. |
| `portfolio_type` | Тип портфеля: консервативный (`conservative`), умеренный (`moderate`) или агрессивный (`aggressive`). |
| `date` | Дата формирования портфеля. |
| `SECID` | Тикер акции на Московской бирже. |
| `weight` | Доля капитала, выделенная на акцию (от 0 до 1). |
| `risk_level` | Категория риска акции на дату формирования портфеля: `low`, `medium` или `high`. |
| `capital` | Общий капитал инвестора в рублях. |
| `amount` | Сумма капитала, выделенная на покупку акции, в рублях. |

**Примечания:**
- Один портфель представлен несколькими строками с одинаковым `portfolio_id`.
- Сумма весов `weight` внутри каждого портфеля равна 1 (100%).
- Значение `capital` одинаково для всех строк одного портфеля.
- Сумма `amount` по всем акциям портфеля равна его общему капиталу.
